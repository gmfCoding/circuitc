FEATURES IMPLEMENTED:
=====================

✅ Matrix Solver
   • LU decomposition with partial pivoting
   • Modified Nodal Analysis (MNA)
   • Forward/backward substitution

✅ Circuit Elements
   • Resistors
   • Capacitors (trapezoidal/backward Euler integration)
   • Inductors (trapezoidal/backward Euler integration)
   • Voltage sources (DC)

✅ Simulation Engine
   • Time-domain simulation
   • Companion models for reactive elements
   • Two-phase execution (startIteration → doStep)
   • Configurable timestep

✅ Test Circuits
   • Voltage divider (resistive)
   • RC charging circuit
   • LC oscillator
   • Multi-node complex circuit

ALGORITHMS USED:
================

Matrix Solver:
--------------
• Crout's Method for LU decomposition
• Partial pivoting for numerical stability
• O(n³) factorization, O(n²) solve

Companion Models:
-----------------
Capacitor:
  R_comp = Δt/(2C)         (trapezoidal)
  I_eq = -V_old/R - I_old

Inductor:
  R_comp = 2L/Δt           (trapezoidal)
  I_eq = V_old/R + I_old

Integration:
  • Trapezoidal (accurate, may oscillate)
  • Backward Euler (stable)
